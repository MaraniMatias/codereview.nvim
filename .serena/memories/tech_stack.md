# Tech Stack

- **Language**: Lua (LuaJIT standard)
- **Platform**: Neovim plugin (requires Neovim >= 0.9)
- **Test framework**: plenary.nvim (busted-style specs, fetched via `make deps`)
- **Linter**: luacheck
- **No formatter** is configured (only luacheck for linting)
- **Dependencies**: plenary.nvim cloned into `.deps/plenary.nvim/`
